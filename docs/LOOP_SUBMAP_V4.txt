子图变体
  optimized_map_window5：实际生产 LocalMapBuilder 的 optimized map 坐标，±5窗口。
  raw_anchor_window5：同一组 scan，inverse(raw_anchor)*raw_neighbor 局部锚定。
  raw_anchor_window2：局部锚定±2短窗口。
  single_frame：仅当前/历史 anchor 原始 body cloud。
  controls_holdout 模式另跑 optimized_anchor_window5：与raw-anchor相同anchor坐标，
  但内部使用 inverse(optimized_anchor)*optimized_neighbor。用于隔离坐标/voxel
  网格变化与raw-vs-optimized内部姿态变化。
  optimized_map_leave_centers_out：生产±5 map子图，source完整排除current scan，
  target完整排除candidate scan，full路径求解；两中心完整cloud仍全部参与评价。
  这仅是未参与本次求解的scan内部holdout，邻scan/odom/历史图因子仍相关，绝不是
  物理独立真值或独立测试集。图里既有因子可能早已使用同一区域的信息。
  所有 source 窗口均截至 current，不能读未来 cloud；历史 target 的 after 邻帧必须
  已在 current 前存在。子图成员、时间间隔、共享原始 scan ID 完整记录；该ID交集
  实际为Bundle keyframe/body-cloud ID，缺失激光packet级溯源，不能证明packet独立。
  注意：map->raw-anchor 同时改变内部姿态、注册坐标和体素网格，不可直接宣称是
  “raw odom 消除了图形变”。若有改善，推荐前须有同坐标 optimized-anchor 控制。

采样与容量
  使用原 LocalMapBuilder，不复制/修改 voxel 算法。记录 merged、voxel_before_cap、
  after_cap 的点数与 XYZ 范围。pre-cap 用 SIZE_MAX 上限的原 builder 获得，最终点集
  用原200000上限builder获得，逐点检查最终是pre-cap序列的相同prefix。
  height仅为 anchor body-relative z proxy 和原 local-ground plane proxy，
  保留原坡度；body.z/map.z 不称物理高度，不推断真实 gravity。

  已核对最终 v3 paced events.csv 全5017行：source_points 最大16490，target_points
  最大24068，两字段>=200000均0。由于截断必返回恰好200000，可排除这些已记录实际
  配准输入上的200k截断。此证据不排除合并、体素化、内部非刚体变形或配准错误。

配准与恢复
  每个变体独立 full Quatro+Nano-GICP 与 fine-only。full 不传原始 SC yaw 到 map。
  fine-only 初值为 At * inverse(P_history)*P_current * inverse(As)。
  As/At 为各 anchor body->solver 坐标变换。恢复：
    T_body_target_source = inverse(At) * T_solver * As
    corrected_current_map = P_history * T_body_target_source
    graph_relative_current_inverse_history = inverse(T_body_target_source)
  fine 证据保留原fitness/overlap/correspondences，在恢复后的 map body pose 再执行
  原5m/1rad pose guard。不调任何阈值。probe不评估竞争候选和跨帧确认，valid字段
  只代表单对几何和pose guard，不代表可入图或已通过完整安全pipeline。

固定结构评价
  每对评价点集始终为两侧完整原始 anchor body clouds，不随solver窗口或高度改变。
  双向全点 NN覆盖(.5m)、p50/p95；原始prior冻结对应的覆盖/距离；固定PCA法向上的
  点到面/法向角；分层低<=.25m、中(.25,3]m、高>3m来自原local-ground proxy。
  法向 k12、邻域半径<=.6m、lambda1>1e-5、lambda0/lambda1<.3，配准前一次冻结。
  点到面/法向只在明确记录的固定可信法向子集上统计；完整距离分母从不删除。
  另列prior-NN<=2m的冻结共同支持proxy，不能称真实可见性或独立真值；prior选择
  有偏，必须与全点一起看。匹配2m bodyXY网格/方位覆盖、target多对一比例、最大
  multiplicity及集中度用于暴露局部重复结构吸附，不自动等价结构正确性。
  没有空间留出则不得声称独立holdout；未把后验nearest重选对应称固定对应。

最终结论
  已排除这批实际配准输入的200k截断；4个固定代表没有证据支持raw/small-window
  替代生产子图，也没有证据证明留扫结构指标可靠区分正常/恶化。不能据4对设置
  新阈值或生成真/假地点标签。保留这些负结果与原始指标。
  fine-only仅证明这4个已接近局部解的固定对可更快到近同解，尚不证明竞争者、
  大初值误差或全序列安全，不推荐替换full竞争验证。主线保持v3策略/阈值/子图；
  内容完全相等的FPFH缓存可作为另一个不改变候选/几何语义的性能实验独立验收。
